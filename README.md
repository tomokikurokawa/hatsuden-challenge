# はつでんチャレンジ

フクモクフェス2026（9/12・9/13／福井県産業会館）出展用の自転車発電アトラクション。
自転車のクランクに付けたワイヤレスセンサーの回転数をブラウザで読み取り、30秒間の発電量を競うゲームです。

## 遊び方

1. 下記URLを **Chrome** で開く
2. 画面右上の「センサー接続」→ ダイアログでセンサー（COOSPO BK9C など）を選ぶ
3. 「スタート！」を押して30秒間ペダルを漕ぐ

**公開URL:** https://hatsuden.atrum-japan.com/

## 動作条件

- **ブラウザは Chrome または Edge**（Web Bluetooth 非対応の Safari / Firefox では動きません）
- **HTTPS か localhost が必須**。上記の公開URLは HTTPS なのでセンサーが使えます。
  社内LANのIPアドレス（`http://192.168.…`）で開くとセンサーだけ動かないので注意。
- センサーは BLE の CSC プロファイル（ケイデンス）に対応したもの。
  スピードモードのセンサーでも仮換算で動きますが、ケイデンスモード推奨です。

## 画面の操作

| 操作 | 内容 |
| --- | --- |
| スタートボタン / Space / Enter | ゲーム開始 |
| 「音 ON / 音 OFF」ボタン | BGM・効果音のミュート切替 |
| 「デバッグ」ボタン または D キー | センサーの生データ表示、疑似走行スライダー |
| 「タイトルに戻る」ボタン | いつでもタイトルへ戻る |

## トラブル時

- **センサーがダイアログに出ない** → センサーを軽く振って起こす。スマホのアプリが繋いでいると PC から見えないので切断する
- **接続が切れた** → 自動で再接続を試み続けます（最大10秒間隔）。復帰しない場合は「センサー接続」を押し直す
- **音が出ない** → ブラウザの自動再生制限のため、一度画面をクリックするまで無音です。スタートを押せば鳴ります

## オフラインで使う場合

会場のネット回線が不安定な場合に備え、ローカル起動も可能です。
このリポジトリをダウンロードし、Python がある PC で以下を実行してください。

```
python -m http.server 8123
```

→ Chrome で http://localhost:8123 を開く

## 技術メモ

- 単一HTMLファイル（`index.html`）＋画像アセットのみ。ビルド不要
- センサー: Web Bluetooth API（CSC / `csc_measurement`）
- BGM・効果音: WebAudio による合成（音源ファイル不要）。発電量に応じてBGMのテンポが変化します
- キャラクター画像は単色背景で生成し、JavaScript側でクロマキー透過しています
